# Histórico de validações

Registro de todas as verificações executadas no projeto, da F0 à entrega. Só execuções reais entram
nesta tabela; o que ainda não foi executado está listado em
[Validado em](../README.md#validado-em), no README.

## Como ler

- Cada linha é uma execução. `idem` repete o valor da linha anterior na mesma coluna.
- **SHA** é o commit testado; antes do primeiro commit, a coluna diz que não havia commits.
- **Comando** traz o comando executado e, quando existe, o código da verificação (`V1` a `V9c`).
  A legenda dos códigos está em [Validado em](../README.md#validado-em).
- **Resultado** traz o exit code, os números do relatório e o ID da execução (run), quando há um.
